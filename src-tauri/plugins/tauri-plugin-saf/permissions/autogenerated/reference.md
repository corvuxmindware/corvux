## Default Permission

Default permissions for the SAF plugin. Grants the folder picker command.

#### This default permission set includes the following:

- `allow-pick-folder`

## Permission Table

<table>
<tr>
<th>Identifier</th>
<th>Description</th>
</tr>


<tr>
<td>

`saf:allow-pick-folder`

</td>
<td>

</td>
</tr>

<tr>
<td>

`saf:allow-pick-folder`

</td>

</td>
</tr>

<tr>
<td>

`saf:deny-pick-folder`

</td>

</td>
</tr>
